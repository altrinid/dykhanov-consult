# Сайт «Дыханов Консалтинг»

Новый сайт [dykhanov-consult.ru](https://dykhanov-consult.ru) вместо старого на Tilda.
Статика на [Astro](https://astro.build) и PHP-обработчик формы заявки.

## Разработка

```sh
npm install
npm run dev       # http://localhost:4321
npm run build     # проверка типов и сборка в dist/
npm run preview   # просмотр собранного сайта
```

В режиме `npm run dev` форма не отправляется: PHP-обработчик работает только на хостинге.
Проверить форму локально можно так: `npm run build && php -S 127.0.0.1:8080 -t dist`.

## Структура

| Путь | Что там |
| --- | --- |
| `src/data/site.ts` | контакты, реквизиты, меню, услуги |
| `src/data/legal.ts` | данные оператора ПД для политики и согласия |
| `src/pages/` | страницы: адрес страницы = путь к файлу |
| `src/content/news/` | новости в Markdown |
| `src/components/` | шапка, подвал, форма заявки, SEO-теги |
| `src/styles/global.css` | цвета, шрифты, общие стили |
| `public/api/send.php` | обработчик формы: проверка, защита от ботов, отправка письма |
| `public/.htaccess` | https, www, редиректы со старых адресов, кеширование |

## Как добавить новость

Создать файл `src/content/news/2026-10-01-zagolovok.md`:

```md
---
title: Заголовок новости
date: 2026-10-01
description: Одно-два предложения для списка новостей и поисковиков
cover: ./2026-10-01-zagolovok.jpg # необязательно; картинка лежит рядом с файлом
---

Текст новости в Markdown.
```

Адрес новости — `/news/2026-10-01-zagolovok/`. Черновик скрывается полем `draft: true`.

## Публикация

Нужен российский хостинг с Apache и PHP 7.4+ (Beget, Timeweb, REG.RU и т. п.):
персональные данные граждан РФ из формы должны собираться на серверах в России (ч. 5 ст. 18 152-ФЗ).

1. `npm run build` (номер счётчика Метрики — в `.env`, см. `.env.example`).
2. Загрузить содержимое `dist/` в корень сайта (`public_html`, `www` или аналог).
3. Если нужны другие адреса для заявок или журнал заявок — положить `form-config.php`
   (по образцу `form-config.example.php`) уровнем выше корня сайта.
4. Включить бесплатный SSL-сертификат в панели хостинга.
5. В REG.RU заменить A-запись домена: сейчас она указывает на Tilda.
6. Добавить SPF-запись хостинга для домена, чтобы письма с заявками не попадали в спам.
7. Отправить тестовую заявку и проверить, что письмо пришло.
8. Добавить сайт в Яндекс Вебмастер и Google Search Console, отправить `sitemap-index.xml`
   и запросить переобход страниц.
