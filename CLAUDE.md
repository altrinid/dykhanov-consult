# dykhanov-consult

Новый сайт «Дыханов Консалтинг» (dykhanov-consult.ru) на Astro вместо старого сайта на Tilda.
Заявки с формы обрабатывает `public/api/send.php` на российском хостинге (152-ФЗ).

## Команды

- `npm install`, `npm run dev`, `npm run build` (astro check + сборка), `npm run preview`
- Проверка формы с перехватом писем:
  `npm run build && php -d sendmail_path="tee -a /tmp/mail.log" -S 127.0.0.1:8080 -t dist`

## Правила

- Тексты сайта на русском; данные компании (контакты, реквизиты, меню) — только в `src/data/site.ts`.
- Адреса старых страниц Tilda не терять: на каждую — 301-редирект в `public/.htaccess`.
- Формы — только с отдельной галочкой согласия на обработку ПД; сторонние сервисы для сбора ПД
  (Google Forms и т. п.) не подключать: данные граждан РФ должны собираться на серверах в РФ.
- `form-config.php`, `.env` и любые пароли в репозиторий не коммитить.

Нужны домены в сети окружения: `registry.npmjs.org`, `web.archive.org`, `static.tildacdn.com`.

3. Тексты — из блоков Tilda (`.t-title`, `.t-descr`, `.t-text`, `.t-name` и т. п.); картинки — из
   `data-original`, `src` и `background-image` (static.tildacdn.com). Оригиналы качать с

Если web.archive.org из окружения не отвечает (соединение обрывается примерно через 12 секунд), пользователь
сохраняет страницы из архива в своём браузере (Ctrl+S → «Веб-страница, только HTML») и загружает их в чат.
